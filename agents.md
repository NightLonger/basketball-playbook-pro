# agents.md — Basketball Playbook Pro

Рабочие заметки для продолжения разработки на другом ПК. Репозиторий: локальный клон `NightLonger/basketball-playbook-pro`.

## Что это за проект
- Статическое веб-приложение (PWA) для рисования баскетбольных схем/комбинаций на SVG-площадке.
- Стек: vanilla JS (ES modules), HTML, CSS, Service Worker (`sw.js`), без сборщика.
- Точка входа: `index.html` → `js/app.js`.

## Быстрый запуск / проверка
- Открыть через локальный статический сервер (или текущий сервер, если уже запущен) и загрузить приложение в браузере.
- `sw.js` в проекте есть, но сейчас **не регистрируется** в `index.html`/`app.js`, поэтому stale service-worker кэш при обычной разработке не мешает.
- Быстрая проверка синтаксиса:
  - `node --check js/app.js js/modules/*.js`

## Ключевые модули
- `js/app.js` — оркестрация UI: нижняя панель/табы, выбор инструментов, размещение игроков, запись/воспроизведение, сохранение/загрузка схем, загрузка комбинаций из playbook.
- `js/modules/court.js` — SVG-площадка, слои, координаты (`getSVGPoint`, `getScreenCTM`).
- `js/modules/players.js` — создание/перетаскивание игроков и мяча, обновление `data-x/data-y`/transform.
- `js/modules/drawing.js` — инструменты рисования (линия, передача/пунктир, движение/стрелка, ведение, заслон, бросок, подбор, ластик), сериализация/восстановление элементов.
- `js/modules/timelinePlayer.js` — PoC таймлайн-плеера: воспроизведение комбинации по ключевым кадрам/трекам и событиям отрисовки через `requestAnimationFrame`.
- `js/modules/playbook.js` — библиотека готовых комбинаций (категории, данные); сценарные таймлайны подключаются по `id`.
- `js/modules/playbookTimelines.js` — все сценарные таймлайны комбинаций (стартовые позиции, треки игроков/мяча, события рисования).
- `js/modules/recorder.js`, `js/modules/history.js`, `js/modules/storage.js`, `js/modules/touch.js`, `js/modules/icons.js`, `js/modules/config.js` — запись/снапшоты, undo/redo, localStorage-схемы, тач-настройки, иконки, конфиг.
- `css/styles.css` — стили приложения, состояния bottom-sheet (`collapsed/half/expanded`), анимации.
- `sw.js` — PWA-кэширование (при изменениях ассетов желательно обновлять версию кэша и список precache).

## Текущее состояние воспроизведения комбинаций
- Есть два подхода:
  1. **Timeline (основной):** если у комбинации есть `timeline`, `app.js` загружает его в `TimelinePlayer` и воспроизводит плавно по трекам/событиям.
  2. **Fallback (старый формат):** для комбинаций без `timeline` строятся снапшоты из `data.players/data.drawings` и проигрываются покадрово.
- **Все 25 комбинаций** в `playbook.js` переведены на timeline; данные лежат в `js/modules/playbookTimelines.js` и подключаются по `id` в конструкторе `PlaybookManager`.
- В каждой комбинации заданы стартовая расстановка, тайминги, движение игроков/мяча и события рисования (заслон, передача, движение, ведение, бросок, метка).
- `TimelinePlayer` интерполирует позиции игроков по трекам, показывает события рисования по времени. Линии/стрелки остаются на площадке как схема, а текстовые метки (`label`) скрываются после `t1`.
- На время розыгрыша (7–10 с) нижняя панель полностью скрывается, площадка освобождает место под плавающий пульт `#playback-hud` с прогрессом, временем и кнопкой «Стоп».
- Вид площадки выбирается автоматически по данным таймлайна: если движение выходит ниже середины (`y > 145`) — full-court, иначе half-court (крупнее и читаемее). После остановки/завершения прежний вид восстанавливается.
- После загрузки комбинации автоматически открывается вкладка Tools, чтобы кнопка ▶️ Play была сразу видна.
- Мяч при владении смещается к краю кружка игрока и не закрывает подпись позиции; при передаче плавно возвращается на трек. Цвет мяча — оранжевый для контраста с площадкой.

## Недавние изменения (в этой рабочей копии)
- Добавлен `js/modules/timelinePlayer.js` и подключён timeline-playback PoC (Pick & Roll).
- Исправления UX/взаимодействий: точность координат на SVG (`court.js`, `getScreenCTM`), стабильность drag игроков/подписей (`players.js`, `styles.css`), компактное поведение нижней панели.
- Начальный экран: панель открывается в «слегка раскрытом» (`half`) состоянии — сразу видны игроки для быстрого размещения, инструменты рисования скрыты до раскрытия.
- Инструмент «Заслон» (`screen`): переименование в UI, иконка ⊥, отрисовка на площадке как перевёрнутая «Т» (интерактивно, в таймлайне и в fallback-рендере комб).
- Инструменты рисования переименованы в UI: `Движение` (arrow), `Передача` (dashed), `Ведение` (wavy), `Линия`, `Заслон`, `Бросок`, `Подбор`, `Ластик`.
- Кнопка «Выделение/курсор» удалена из панели; после размещения игрока инструмент автоматически выключается (одна позиция — одно размещение).
- Позиции `PG/SG/SF/PF/C/ball` уникальны: повторная кнопка блокируется, пока игрок не удалён/не очищена площадка. `DEF` можно ставить несколько раз (нужно для защиты).
- Компактный режим панели (`half`) показывает все позиции игроков и заголовок `Drawing`, но скрывает кнопки рисования до раскрытия.
- Подсказка инструмента (`#floating-hint`) показывается под шапкой, а не над нижней панелью, и автоматически скрывается через 5 с — её не перекрывают компактная панель и нижняя адресная строка Safari на iPhone. Выбранный инструмент постоянно виден в шапке (`#active-tool-chip`): иконка + название, на экранах ≤400 px — только иконка.
- Сохранение схем переведено на `attrs`-формат (с совместимостью загрузки старых `outerHTML`-схем).
- Добавлены сценарные таймлайны для всех 13 базовых комбинаций: `pick-roll-basic`, `zone-defense-2-3`, `fast-break`, `isolation`, `give-go`, `post-up`, `motion-offense`, `man-to-man`, `full-court-press`, `zone-3-2`, `inbound-side`, `last-shot`, `screen-away`.
- Добавлены 8 новых комбинаций с воспроизведением (по две в каждую категорию): `horns-set`, `dho-wing` (basic), `ucla-cut`, `hammer` (offense), `zone-1-3-1`, `box-and-one` (defense), `blob-stack`, `ato-quick` (special). У всех есть стартовая расстановка, треки игроков/мяча, пасы, заслоны, движения и завершение.
- Добавлен второй батч: `spain-pick-roll`, `floppy` (offense), `press-1-2-2` (defense), `slob-box` (special). Spain P&R — заслон + back screen на защитнике C; Floppy — выбор заслона шутером; 1-2-2 — прессинг с ловушкой на бровке; SLOB box — вбрасывание сбоку из бокса.
- У зонных защит (`zone-defense-2-3`, `zone-3-2`) задняя линия опущена к кольцу (`y≈22–32`), чтобы расстановка читалась как реальная зона, а не как дуга.
- В Pick & Roll синхронизированы пас и скат центрового: мяч приходит в точку завершения примерно в момент выхода C к кольцу.
- Во время воспроизведения скрываются `#floating-hint` и `#active-tool-chip`, чтобы подсказка инструмента не перекрывала розыгрыш.
- Проверено в Chromium (Selenium): все 25 комбо загружаются и играются, площадка не пересекается с пультом, кнопка «Стоп» появляется/скрывается, ошибок в консоли нет.
- Для новых комбинаций проверено: число акторов совпадает с числом треков, координаты в пределах `150×280`, тайминги отсортированы и не выходят за `duration`; в Chromium все 12 новых розыгрышей доходят до конца, HUD и прогресс работают, метки скрываются после `t1`.

## Известные проблемы / технический долг
- **Наконечник `Движение` (arrow) — исправлен.** Причина: CSS-правило `#drawing-layer path { fill: none; }` применялось и к `<path>` внутри `<marker>`, делая треугольник прозрачным. Теперь селектор ограничен прямыми дочерними элементами слоя (`#drawing-layer > path`). Проверено в Chromium (marker fill = `rgb(0,122,255)`).
- У комбинаций защит (`zone-defense-2-3`, `zone-3-2`) анимируется только защита + мяч, без игроков нападения — это схема сдвигов зоны, а не полноценный розыгрыш 5-на-5.
- `zone-defense-2-3` / `zone-3-2`: стартовые позиции в `timeline.initialPlayers` исправлены, но старые fallback-позиции в `combo.data.players` остались прежними (не используются, пока есть timeline).
- `sw.js`: список precache обновлён (`playbookTimelines.js`), но регистрации service worker сейчас нет.
- Нет единого редактора/формата для авторинга timeline-комбинаций из UI (сейчас запись даёт снапшоты; сценарные таймлайны задаются данными).
