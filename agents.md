# agents.md — Basketball Playbook Pro

Рабочие заметки для продолжения разработки на другом ПК. Репозиторий: локальный клон `NightLonger/basketball-playbook-pro`.

## Что это за проект
- Статическое веб-приложение (PWA) для рисования баскетбольных схем/комбинаций на SVG-площадке.
- Стек: vanilla JS (ES modules), HTML, CSS, Service Worker (`sw.js`), без сборщика.
- Точка входа: `index.html` → `js/app.js`.

## Быстрый запуск / проверка
- Открыть через локальный статический сервер (или текущий сервер, если уже запущен) и загрузить приложение в браузере.
- После изменений **обязательно делать жёсткое обновление** (`Ctrl+F5`), т.к. активен `sw.js` и может отдаваться закэшированная версия.
- Быстрая проверка синтаксиса:
  - `node --check js/app.js js/modules/*.js`

## Ключевые модули
- `js/app.js` — оркестрация UI: нижняя панель/табы, выбор инструментов, размещение игроков, запись/воспроизведение, сохранение/загрузка схем, загрузка комбинаций из playbook.
- `js/modules/court.js` — SVG-площадка, слои, координаты (`getSVGPoint`, `getScreenCTM`).
- `js/modules/players.js` — создание/перетаскивание игроков и мяча, обновление `data-x/data-y`/transform.
- `js/modules/drawing.js` — инструменты рисования (линия, передача/пунктир, движение/стрелка, ведение, заслон, бросок, подбор, ластик), сериализация/восстановление элементов.
- `js/modules/timelinePlayer.js` — PoC таймлайн-плеера: воспроизведение комбинации по ключевым кадрам/трекам и событиям отрисовки через `requestAnimationFrame`.
- `js/modules/playbook.js` — библиотека готовых комбинаций (категории, данные, timeline для поддерживаемых комбинаций).
- `js/modules/recorder.js`, `js/modules/history.js`, `js/modules/storage.js`, `js/modules/touch.js`, `js/modules/icons.js`, `js/modules/config.js` — запись/снапшоты, undo/redo, localStorage-схемы, тач-настройки, иконки, конфиг.
- `css/styles.css` — стили приложения, состояния bottom-sheet (`collapsed/half/expanded`), анимации.
- `sw.js` — PWA-кэширование (при изменениях ассетов желательно обновлять версию кэша и список precache).

## Текущее состояние воспроизведения комбинаций
- Есть два подхода:
  1. **Timeline (приоритетный для реалистичных розыгрышей):** если у комбинации есть `timeline`, `app.js` загружает его в `TimelinePlayer` и воспроизводит плавно по трекам/событиям.
  2. **Fallback (старый формат):** для комбинаций без `timeline` строятся снапшоты из `data.players/data.drawings` и проигрываются покадрово.
- PoC timeline реализован для `pick-roll-basic` (`js/modules/playbook.js`).
- `TimelinePlayer` интерполирует позиции игроков по трекам, показывает события рисования (линии/заслон/пас/бросок и т.д.) по времени.
- Цель направления: воспроизведение должно имитировать осмысленное выполнение комбинации (тайминг, роли, движение мяча/игроков), а не случайные/неестественные перемещения.

## Недавние изменения (в этой рабочей копии)
- Добавлен `js/modules/timelinePlayer.js` и подключён timeline-playback PoC (Pick & Roll).
- Исправления UX/взаимодействий: точность координат на SVG (`court.js`, `getScreenCTM`), стабильность drag игроков/подписей (`players.js`, `styles.css`), компактное поведение нижней панели.
- Начальный экран: панель открывается в «слегка раскрытом» (`half`) состоянии — сразу видны игроки для быстрого размещения, инструменты рисования скрыты до раскрытия.
- Инструмент «Заслон» (`screen`): переименование в UI, иконка ⊥, отрисовка на площадке как перевёрнутая «Т» (интерактивно, в таймлайне и в fallback-рендере комб).
- Инструменты рисования переименованы в UI: `Движение` (arrow), `Передача` (dashed), `Ведение` (wavy), `Линия`, `Заслон`, `Бросок`, `Подбор`, `Ластик`.
- Кнопка «Выделение/курсор» удалена из панели; после размещения игрока инструмент остаётся активным для быстрого добавления нескольких игроков.
- Сохранение схем переведено на `attrs`-формат (с совместимостью загрузки старых `outerHTML`-схем).

## Известные проблемы / технический долг
- **Наконечник у `Движение` (arrow) не отображается стабильно у пользователя** — требуется отладка в браузере (SVG marker/visibility/слои/кэш/SW/координаты). Сейчас логика маркера есть в drawing/timeline/fallback/restore, но проблема не закрыта.
- Набор готовых комбинаций в `playbook.js` в основном без `timeline` (кроме `pick-roll-basic`) — воспроизведение для них менее реалистичное.
- `sw.js`: при изменении набора модулей/ассетов нужно синхронизировать precache-список и версию кэша, иначе на другом устройстве возможны stale-ошибки.
- Нет единого редактора/формата для авторинга timeline-комбинаций из UI (сейчас запись даёт снапшоты; сценарные таймлайны задаются данными).

## Процесс работы (рекомендация)
